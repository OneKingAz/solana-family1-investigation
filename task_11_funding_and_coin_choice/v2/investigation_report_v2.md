## 1. «Создатель монеты» → плательщик инициализации пула

В заданиях №9 и №11 поле `created_by` — это первый ключ (`accountKeys[0]`) транзакции создания пула, то есть **плательщик комиссии**.
Дальше оно называется `pool_init_payer`. Отдельно прочитаны данные самих счетов пулов (`getMultipleAccounts`, `pool_creator_fields.csv`):

| Проверка | Результат |
|---|---|
| Пулы PumpSwap: поле `creator` в данных пула (смещение 11) = `pool_init_payer` | **76 из 78**; в 2 пулах плательщик не найден, поле `creator` = `6e7XUsDb` |
| Пулы PumpSwap: поле `coin_creator` (смещение 211) | пустое (нули) во всех 78 — монеты не с pump.fun, поле не заполнено |
| 7 пулов Meteora DAMM v2 | поле создателя не читалось (другая раскладка) |
| Токены: mint authority и freeze authority | **отозваны (`None`) у всех 85** |

**Подтверждено:** адрес, который везде называется «создателем», — это **создатель пула**. Так записано в данных самого пула PumpSwap, и он же
оплатил его инициализацию.

**Не установлено:** кто выпустил сам токен. Полномочия токена отозваны, поэтому из текущего состояния токена это не видно. Для проверки нужна
самая первая транзакция каждого токена, а это перебор всей его истории (тысячи подписей на монету). Это не делалось. Дальше везде
«создатель» = создатель пула.

## 4. Проверка значимости с сохранением смен (`null_distributions_any.csv`, `null_distributions_ge01.csv` — все значения)

**Нулевая гипотеза:** последовательность создателей монет и последовательность последних пополнивших — независимые процессы. У каждой
своя временная структура: смены идут блоками.

| Тест | Вариант А (любые) | Вариант Б (от 0.1 SOL) |
|---|---|---|
| Наблюдаемых совпадений | 51 | 61 |
| Блоков (смен) в последовательности пополнивших / создателей | 23 / 9 | **5 / 9** |
| а) Циклический сдвиг пополнивших относительно создателей, все 104 сдвига: среднее / максимум / p | 14.2 / 52 / **0.038** | 19.4 / 64 / **0.067** |
| б) Перестановка целых смен, 5 000 раз: среднее / 95% / p | 13.4 / 38 / 0.0008 | 20.1 / 64 / **0.082** |
| в) Перестановка отдельных сессий, 5 000 раз (как в версии 1; считает сессии независимыми) | p = 0.0002 | p = 0.0002 |

**Вывод о значимости.** Если считать сессии независимыми (тест «в»), совпадение крайне неслучайно. Но если сохранить структуру смен
(тесты «а» и «б»), то в основном варианте Б (без пыли) p = 0.067–0.082. Это **не значимо на уровне 5%**. Причина в том, что
пополняющих смен всего 5, и статистических единиц тоже по сути 5, а не 105. В варианте А p ниже (0.038 и 0.0008), но там смены
искусственно дробятся пылевыми переводами, поэтому на этот вариант опираться нельзя.

**Исправление к версии 1:**
- утверждение «p < 0.0002» верно только для теста, который считает сессии независимыми;
- с учётом смен статистически доказать связь «кто финансирует — чьи монеты» на этих данных **не удаётся**: слишком мало смен;
- код всех трёх тестов и все значения нулевых распределений теперь опубликованы.
