# Задание №9. Порядок входа девяти кошельков в монету

Дата: 18.11.2026. Скрипт `inv09.py`. Время — UTC. Данные:
- покупки из задания №7: 58 монет, которые покупали все девять (51 в PumpSwap, 7 в Meteora DAMM v2);
- номер транзакции внутри блока: `getBlock`, только подписи, 520 блоков;
- история пула до первой покупки девяти: `getSignaturesForAddress` с `before` = первая покупка девяти;
- до 10 самых ранних транзакций пула: `getTransaction`, кто создал пул и кто покупал первым.

**Первая покупка кошелька в монете** — его самая ранняя операция BUY. При нескольких операциях в одном слоте выбирается та, что раньше
по номеру в блоке. Номер в блоке найден для 521 из 522 первых покупок.

## 1. Когда входят девять

| | |
|---|---|
| От создания пула до первой покупки девяти | **6–50 с** (медиана ~20 с), один случай — 135 с |
| Транзакций пула до первой покупки девяти | медиана 26 (от 1 до 296, один пул — 1 246) |
| Первым после создания покупает кто-то из девяти | **0 из 58** |
| Кто покупает первым | создатель этой же монеты (`Czg8kh3E` 11, `6e7XUsDb` 6, `GLEBhVYd` 3, `29iqxoNv` 2), пыль-боты (`cocoEehe` 4, `kiwiC4pg` 2) и другие |
| От первой до девятой первой покупки девяти | медиана **75.5 с** (от 15 до 1 484 с), медиана 345 слотов |
| Девять первых покупок в одном слоте | нет: максимум 1 кошелёк на слот (медиана) |
| Первая покупка, WSOL | медиана **4.007 SOL**, обычно 3.2–5.0 SOL |

Девять входят не первыми, а через 6–50 секунд после создания пула: после создателя и первых покупателей, по одному, растянуто на
~1–2 минуты.

## 2. Есть ли повторяющийся порядок

| Проверка | Результат |
|---|---|
| Одинаковый порядок у двух монет | **ни разу**: все 58 порядков разные |
| Кто чаще всего первый | `ByrLc8xW` 9, `9YHUi5cV` 9, `AHXA5vwT` 8, `7bL6uz3P` 7, `6k64Wxj9` 6, `2RCjTNMY` 6, `B4ExgwFB` 5, `5KJEmUWT` 4, `GN1gj63D` 4 (при случайном порядке ожидается ~6.4) |
| Средний номер кошелька | 4.62–5.26 у всех (при случайном порядке — 5.0) |
| Согласованность порядка по 58 монетам (коэффициент Кендалла W) | **0.0064**; при случайном порядке: среднее 0.0173, 95-й перцентиль 0.033 |
| Вероятность получить такое W или выше при случайном порядке | 0.95 |
| Вероятность получить такое W или ниже при случайном порядке | 0.056 |
| Для каждой пары кошельков: доля монет, где A раньше B (или B раньше A, что больше) | медиана 0.543, максимум 0.603 (0.5 = как случайно) |

Порядок входа **не повторяется** и статистически не отличается от случайного. Он даже немного «ровнее» случайного (каждый кошелёк
бывает на каждом месте примерно поровну), но разница не значима (p = 0.056).

## 3. Покупают ли «кругами»

| Проверка | Результат |
|---|---|
| Доля окон из 9 покупок подряд, где все 9 кошельков разные | медиана **0** по монетам; при случайной очереди из 9 кошельков ожидается 0.0009 |
| Интервал между покупками одного кошелька в одной монете | медиана **21 с** |

Строгой очерёдности («каждый по разу, потом снова») нет. Каждый кошелёк покупает сам по себе, в среднем раз в ~21 с.

По самой ранней транзакции пула (создание пула) создатель установлен для **всех 58 монет**, в том числе для 24 монет, создатель которых

## Итог

**ПОДТВЕРЖДЕНО:**
- девять входят в монету через 6–50 с после создания пула;
- первыми не бывают никогда: первым почти всегда покупает сам создатель или пыль-боты;
- входят по одному, растянуто на ~1–2 мин, первая покупка ~3–5 SOL;
- 49 из 58 монет созданы адресами, которые финансируют эти кошельки, ещё 4 — создателем Семьи 1 `GLEBhVYd`.

**НЕ ПОДТВЕРЖДЕНО:** повторяющийся порядок входа. Порядок каждый раз другой и не отличается от случайного; строгих «кругов» нет.

**НЕВОЗМОЖНО УСТАНОВИТЬ этими данными:** по какому правилу выбирается момент входа каждого кошелька. Похоже на независимые таймеры
или случайную задержку: 6–50 с после создания, затем покупки примерно раз в 21 с. Это гипотеза.
